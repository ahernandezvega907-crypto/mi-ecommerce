# Mi E-commerce (React + FastAPI)

Tienda online con carrito de compras y simulación de pago.

- **Frontend:** React + Vite (Desplegado en Vercel)
- **Backend:** Python + FastAPI + SQLite (Desplegado en Render)

🔗 [Ver Documentación de la API](https://mi-ecommerce-apibackend.onrender.com/docs)
